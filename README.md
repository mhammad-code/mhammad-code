### 🚀 Featured Projects

- **[AdverShield – Adversarial ML Battle Arena](https://github.com/mhammad-code)**
  Full-stack platform where AI agents compete to attack and defend image classifiers using 12+ attack algorithms (FGSM, PGD, CW) and 13 defense mechanisms via ART. Integrated Llama 3.3 (Groq API) for strategy generation, Q-Learning for adaptive behavior, GradCAM visualizations, and a real-time analytics dashboard.

- **[Blood Bank Emergency Matching System (DSA)](https://github.com/mhammad-code)**
  C++ hospital network simulation using a Max-Heap Priority Queue for emergency-first blood request scheduling and Dijkstra's Algorithm on a 20-node graph to locate the nearest available blood supply. Includes FIFO-based inventory with 42-day expiry tracking, binary file persistence, and a GenericManager template class.

- **[Grocery Store Management System](https://github.com/mhammad-code)**
  GUI-based desktop application built with C# WinForms integrated with a MySQL database, supporting full CRUD operations for product and user data with a user-friendly interface.

- **[Ride Booking System (OOP-Based with GUI)](https://github.com/mhammad-code)**
  Java GUI application for booking and managing rides, applying OOP principles including encapsulation, class design, and modular programming.
